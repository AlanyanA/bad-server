# Как протестировать проект

## 1. Подготовка
1. Убедитесь, что у вас установлен Docker.
2. Откройте терминал в корне проекта.

## 2. Запуск проекта
```bash
docker compose up -d
```

## 3. Наполнение базы данных
Следуйте инструкции из файла [.dump/README.md](.dump/README.md).

## 4. Проверка основных сценариев
- Откройте страницу http://localhost/ и убедитесь, что загружаются продукты.
- Перейдите на http://localhost/login/ и попробуйте авторизоваться.
- Откройте http://localhost/admin/ и проверьте доступ к админке.

## 5. Дополнительно
- Для проверки API можно использовать коллекцию Postman из [backend/src/public/weblarek.postman.json](backend/src/public/weblarek.postman.json).
- Если что-то не работает, проверьте логи контейнеров:
```bash
docker compose logs -f
```
