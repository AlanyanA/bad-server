# PROJECT EXPLANATION

Проект представляет собой backend для интернет-магазина WebLarek. Основная задача сервера — принимать запросы от фронтенда, обрабатывать авторизацию, выдавать CSRF-токены и работать с данными пользователей и заказов.

## Как устроен проект
- Express используется как веб-сервер.
- Mongoose подключается к MongoDB для работы с сущностями.
- Middleware отвечает за авторизацию, проверку CSRF, CORS и обработку ошибок.
- Маршруты разделены по функциональности: авторизация, продукты, заказы, загрузка файлов.

## Пользовательский поток
1. Пользователь открывает приложение и получает доступ к публичным маршрутам.
2. Для чувствительных действий сервер выдаёт CSRF-токен.
3. После авторизации клиент получает токен доступа и может работать с личными данными и заказами.
4. При ошибке сервер возвращает понятное сообщение и код ответа.

## Почему были внесены изменения
Основная проблема заключалась в том, что backend не успевал подняться в CI, потому что зависел от MongoDB. Из-за этого тесты не могли получить CSRF-токен и падали с ошибкой 502.

## Технологии
- Node.js и Express
- TypeScript
- Mongoose
- JWT и cookies
- Helmet, CORS, rate limiting
