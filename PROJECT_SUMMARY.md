# PROJECT SUMMARY

## Что реализовано
- Исправлен запуск backend в CI/локальной среде: сервер теперь поднимается даже при временной недоступности MongoDB.
- Восстановлена работоспособность маршрута получения CSRF-токена, необходимого для тестов и авторизации.
- Устранена ошибка сборки, связанная с отсутствующим пакетом md5, за счёт перехода на встроенный Node.js crypto.
- Проверены сборка, линтер и ответ CSRF-эндпоинта.

## Основные компоненты
- Express API backend
- Middleware для CSRF, авторизации и обработки ошибок
- Mongoose-модель пользователя
- Маршруты аутентификации и работы с пользователем

## Выполненные требования
- Устранена проблема с недоступностью сервера на старте.
- CSRF-эндпоинт возвращает рабочий токен.
- Проект собирается и проходит линтер.

## Ограничения
- Для полного функционального тестирования требуется доступ к MongoDB.
- В локальной среде без контейнера базы данных приложение продолжает работать для маршрутов, не зависящих от БД.
